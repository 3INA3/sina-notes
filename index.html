۱. تحلیل الگوریتم — چقدر طول می‌کشد؟

آنالوژی: فرض کنید می‌خواهید یک کتاب را در کتابخانه پیدا کنید. اگر کتاب‌ها به‌هم‌ریخته باشند، ممکن است مجبور شوید همه‌ی قفسه‌ها را یکی‌یکی نگاه کنید (کند). اگر کتاب‌ها بر اساس حروف الفبا مرتب باشند، خیلی سریع‌تر پیدا می‌کنید (سریع). تحلیل الگوریتم یعنی بفهمیم «چقدر کار» لازم است تا مسئله حل شود وقتی ورودی بزرگ می‌شود.

وقتی برنامه‌ای می‌نویسیم، دو چیز مهم است:

  • زمان — چند عملیات طول می‌کشد؟ (تابع پیچیدگی f(n))
  • حافظه — چقدر فضای اضافی لازم است؟

ما معمولاً فقط به «بدترین حالت» و «بزرگ‌ترین توان» نگاه می‌کنیم. مثلاً اگر f(n) = 2n² + n + 1 باشد، فقط n² مهم است و می‌گوییم O(n²).

def worker(arr: list[int], index: int) -> int:
    """دسترسی مستقیم: کار به اندازه‌ی لیست بستگی ندارد → O(1)"""
    return arr[index]          # فقط یک خواندن از حافظه


def linear_sum(arr: list[int]) -> int:
    """هر عنصر دقیقاً یک بار دیده می‌شود → O(n)"""
    total = 0                  # یک متغیر کمکی → حافظه O(1)
    for element in arr:        # حلقه n بار اجرا می‌شود
        total += element       # جمع کردن
    return total


if __name__ == "__main__":

شرط مهم: آرایه باید مرتب باشد. ایده‌ی ساده: وسط را نگاه کن. اگر هدف بزرگ‌تر بود، نیمه‌ی چپ را دور بریز. اگر کوچک‌تر بود، نیمه‌ی راست را دور بریز. هر بار بازه نصف می‌شود.

Python — binary_search
def binary_search(arr: list[int], target: int) -> int:
    """اندیس target را برمی‌گرداند یا -1 اگر نبود.
    زمان: O(log n)   حافظه: O(1)"""
    low, high = 0, len(arr) - 1          # دو اشاره‌گر به دو سر
    while low <= high:                   # تا وقتی بازه خالی نشده
        mid = (low + high) // 2          # وسط را حساب کن
        if arr[mid] == target:
            return mid                   # پیدا شد!
        elif arr[mid] < target:
            low = mid + 1                # برو سمت راست
        else:
            high = mid - 1               # برو سمت چپ
    return -1                            # پیدا نشد


if __name__ == "__main__":
    nums = [1, 3, 4, 6, 7, 8, 10]
    print(binary_search(nums, 7))   # 4
    print(binary_search(nums, 5))   # -1
توضیح خط‌به‌خط binary_search:
  1. low, high = 0, len(arr)-1 — بازه‌ی جست‌وجو از اول تا آخر آرایه.
  2. while low <= high — تا وقتی بازه حداقل یک عنصر دارد ادامه بده.
  3. mid = (low+high)//2 — اندیس وسط (تقسیم صحیح تا اعشار نیاید).
  4. اگر arr[mid] == target — پیدا شد، اندیس را برگردان.
  5. اگر هدف بزرگ‌تر است → low = mid+1 (نیمه‌ی چپ را دور بریز).
  6. اگر هدف کوچک‌تر است → high = mid-1 (نیمه‌ی راست را دور بریز).
  7. اگر حلقه تمام شد و پیدا نشد → -1.

مرتب‌سازی ادغامی (Merge Sort)

ایده: لیست را نصف کن، هر نیمه را مرتب کن، بعد دو لیست مرتب را با هم ادغام کن. این کار را آن‌قدر تکرار کن تا به لیست‌های یک‌عنصری برسی (که خودش مرتب است).

[5 2 9 1]
   /    \
[5 2]  [9 1]        ← تقسیم
[5][2] [9][1]
  \ /    \ /
[2 5]  [1 9]        ← ادغام
    \  /
  [1 2 5 9]
Python — merge_sort
def merge_sort(arr: list[int]) -> list[int]:
    """همیشه O(n log n) زمان، O(n) حافظه اضافی."""
    if len(arr) <= 1:                    # شرط توقف: لیست ۱ یا ۰ عنصری
        return arr
    mid = len(arr) // 2
    left  = merge_sort(arr[:mid])        # نیمه‌ی چپ را مرتب کن
    right = merge_sort(arr[mid:])        # نیمه‌ی راست را مرتب کن
    # حالا دو لیست مرتب را ادغام می‌کنیم
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]    # باقی‌مانده‌ها را بچسبان


if __name__ == "__main__":
    print(merge_sort([5, 2, 9, 1, 7]))   # [1, 2, 5, 7, 9]
توضیح خط‌به‌خط merge_sort:
  1. if len(arr) <= 1 — اگر لیست خالی یا تک‌عنصری باشد، خودش مرتب است؛ برگردان.
  2. mid = len(arr) // 2 — نقطه‌ی وسط را پیدا کن (تقسیم صحیح).
  3. left = merge_sort(arr[:mid]) — نیمه‌ی چپ را بازگشتی مرتب کن.
  4. right = merge_sort(arr[mid:]) — نیمه‌ی راست را هم مرتب کن.
  5. out, i, j = [], 0, 0 — لیست نتیجه و دو اشاره‌گر برای پیمایش left و right.
  6. حلقه‌ی while: همیشه عنصر کوچک‌تر را به out اضافه کن و اشاره‌گرش را جلو ببر.
  7. return out + left[i:] + right[j:] — هر کدام که تمام نشده، باقی‌مانده‌اش را بچسبان.

  4. Insertion Sort را پیاده کنید و پیچیدگی بهترین و بدترین حالت را در کامنت بنویسید.
  5. تابعی بنویسید که در O(n) بگوید آیا آرایه از قبل صعودی مرتب است یا نه.

۱) ادغام دو آرایهٔ مرتب

مفهوم: مثل مرحلهٔ merge در Merge Sort. دو اشاره‌گر از ابتدای هر آرایه جلو می‌روند و همیشه عنصر کوچک‌تر را به خروجی می‌گذارند. وقتی یکی تمام شد، باقی‌ماندهٔ دیگری چسبانده می‌شود. این کار O(n+m) است چون هر عنصر دقیقاً یک‌بار دیده می‌شود.
راه‌حل ۱
def merge_sorted(a: list[int], b: list[int]) -> list[int]:
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    return out + a[i:] + b[j:]

۲) binary_search بازگشتی با اولین رخداد

مفهوم: وقتی عنصر پیدا شد، به‌جای برگشت فوری، سمت چپ را هم جست‌وجو کن تا اولین اندیس را پیدا کنی. شرط توقف: اگر low > high → -1.
راه‌حل ۲
def binary_first(arr, target, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    if low > high:
        return -1
    mid = (low + high) // 2
    if arr[mid] == target:
        left = binary_first(arr, target, low, mid - 1)
        return left if left != -1 else mid
    if arr[mid] < target:
        return binary_first(arr, target, mid + 1, high)
    return binary_first(arr, target, low, mid - 1)

۳) تعداد مقایسه‌ها

مفهوم: هر مقایسه بازه را نصف می‌کند. بعد از k بار نصف شدن، اندازه به ۱ می‌رسد → n / 2^k ≈ 1 → k ≈ log₂ n. در پایتون: math.ceil(math.log2(n)) برای n≥1 (و برای n=1 مقدار ۰ یا ۱ بسته به تعریف).
راه‌حل ۳
import math
def count_comparisons(n: int) -> int:
    if n <= 0:
        return 0
    return math.ceil(math.log2(n)) if n > 1 else 1

۴) Insertion Sort

مفهوم: مثل مرتب کردن کارت‌های بازی در دست. کارت‌ها را یکی‌یکی برمی‌داری و در جای درست بین کارت‌های قبلی قرار می‌دهی. بهترین حالت (آرایه مرتب): O(n). بدترین حالت (نزولی): O(n²).
راه‌حل ۴
def insertion_sort(arr: list[int]) -> list[int]:
    # بهترین: O(n)  |  بدترین: O(n²)
    a = arr[:]
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

۵) بررسی مرتب بودن

مفهوم: فقط کافی است هر عنصر از عنصر بعدی بزرگ‌تر نباشد. یک پیمایش خطی کافی است → O(n).

def is_sorted(arr: list[int]) -> bool:
    for i in range(len(arr) - 1):
        if arr[i] > arr[i + 1]:
            return False
    return True

۶) اندازه‌گیری زمان

مفهوم: برای دیدن تفاوت عملی پیچیدگی‌ها. merge_sort برای n بزرگ‌تر هنوز قابل قبول است اما linear_sum فقط جمع ساده است و سریع‌تر.
راه‌حل ۶
import time, random
def measure(n):
    data = [random.randint(0, 10**6) for _ in range(n)]
    t0 = time.perf_counter(); linear_sum(data); t1 = time.perf_counter()
    t2 = time.perf_counter(); merge_sort(data); t3 = time.perf_counter()
    print(f"n={n}: sum={t1-t0:.4f}s  merge={t3-t2:.4f}s")
measure(10**4); measure(10**5)

۲. پشته (Stack) — آخرین ورودی، اولین خروجی

آنالوژی روزمره: یک بسته‌ی بشقاب را تصور کنید. بشقاب جدید را روی بقیه می‌گذارید (push). وقتی بشقاب می‌خواهید، از بالا برمی‌دارید (pop). هیچ‌وقت از وسط یا پایین برنمی‌دارید. این همان LIFO است: Last In, First Out.

پشته فقط از یک طرف (بالا / TOP) کار می‌کند. دو عملیات اصلی:

  • push(x) — عنصر را روی پشته بگذار (شرط: پر نباشد → Overflow)
  • pop() — عنصر بالای پشته را بردار (شرط: خالی نباشد → Underflow)
  • peek() — فقط ببین بالای پشته چیست، بدون برداشتن

🎬 انیمیشن پشته — خودت امتحان کن

پشته خالی است — یک مقدار وارد کن و push بزن
هر push یک مربع از بالا اضافه می‌کند (TOP). هر pop مربع بالای را برمی‌دارد. رنگ نارنجی = TOP
push(1) → [1]
push(2) → [1, 2]     TOP سمت راست
push(3) → [1, 2, 3]
pop()   → 3          حالا [1, 2]
همه‌ی عملیات: O(1)  (ثابت — به اندازه‌ی پشته بستگی ندارد)
Python — کلاس Stack با توضیح
class Stack:
    """پشته با ظرفیت محدود — ساده‌ترین پیاده‌سازی با list پایتون."""

    def __init__(self, limit: int = 100) -> None:
        self.items: list = []       # لیست خالی برای نگه‌داری عناصر
        self.limit = limit          # حداکثر ظرفیت

    def is_empty(self) -> bool:
        return not self.items       # اگر لیست خالی باشد True

    def push(self, x) -> bool:
        if len(self.items) >= self.limit:   # اگر پر بود
            return False                    # Overflow — جا نیست
        self.items.append(x)                # به انتهای لیست اضافه کن
        return True

    def pop(self):
        if self.is_empty():                 # اگر خالی بود
            raise IndexError("stack is empty")  # Underflow
        return self.items.pop()             # آخرین عنصر را بردار

    def peek(self):
        if self.is_empty():
            raise IndexError("stack is empty")
        return self.items[-1]               # فقط نگاه کن، برندار

    def show(self) -> None:
        print(*reversed(self.items))        # از TOP به پایین چاپ کن


if __name__ == "__main__":
    s = Stack()
    s.push(10); s.push(20); s.push(30)
    s.show()                    # 30 20 10
    print(s.peek())             # 30
    print(s.pop())              # 30
    s.show()                    # 20 10
توضیح خط‌به‌خط کلاس Stack:
  1. self.items = [] — یک لیست خالی پایتون؛ انتهای لیست = TOP پشته.
  2. is_empty — اگر لیست خالی باشد، پشته خالی است.
  3. push — اول ظرفیت را چک می‌کند (Overflow). بعد با append به انتها اضافه می‌کند → O(1).
  4. pop — اول خالی بودن را چک می‌کند (Underflow). بعد با list.pop() آخرین عنصر را برمی‌دارد → O(1).
  5. peek — فقط items[-1] را برمی‌گرداند؛ لیست تغییر نمی‌کند.
  6. show — با reversed از بالا به پایین چاپ می‌کند تا شبیه پشته واقعی باشد.

کاربردهای واقعی پشته

  1. دکمه‌ی Undo در ویرایشگر متن — آخرین تغییری که دادی، اول برمی‌گردد.
  2. Call Stack — وقتی تابعی تابع دیگری را صدا می‌زند، آدرس بازگشت در پشته ذخیره می‌شود.
  3. بررسی پرانتزها — هر پرانتز باز را push کن، هر بسته‌ای که آمد باید با آخرین باز جور باشد.
  4. تبدیل مبنا — باقی‌مانده‌ها به ترتیب معکوس تولید می‌شوند، پشته آن‌ها را درست می‌چیند.

Python — d2b
def d2b(n: int) -> str:
    """تبدیل دهدهی به دودویی با پشته."""
    if n == 0:
        return "0"
    s = Stack()
    while n:
        s.push(n % 2)           # باقی‌مانده را push کن
        n //= 2                 # خارج‌قسمت را ادامه بده
    out = ""
    while not s.is_empty():
        out += str(s.pop())     # از بالا بخوان → ترتیب درست
    return out


print(d2b(13))   # 1101
print(d2b(7))    # 111
print(d2b(0))    # 0

Python — balanced
def balanced(text: str) -> bool:
    """آیا همه‌ی پرانتزها، براکت‌ها و آکولادها درست جفت شده‌اند؟"""
    pairs = {")": "(", "]": "[", "}": "{"}   # بسته‌ها → بازها
    s = Stack()
    for ch in text:
        if ch in "([{":                      # پرانتز باز
            s.push(ch)
        elif ch in pairs:                    # پرانتز بسته
            if s.is_empty() or s.pop() != pairs[ch]:
                return False                 # جفت نبود یا پشته خالی
    return s.is_empty()                      # در پایان پشته باید خالی باشد


print(balanced("{[()]}"))   # True
print(balanced("(]"))       # False
print(balanced("((a+b)"))   # False (یک باز اضافی)

پشته با لیست پیوندی

اگر بخواهیم ظرفیت پویا داشته باشیم، می‌توان پشته را روی لیست یک‌طرفه ساخت: head همان TOP است.

Python — Stack با Linked List
class LLNode:
    def __init__(self, data):
        self.data = data
        self.next = None

class StackLL:
    def __init__(self):
        self.top = None

    def push(self, x):
        n = LLNode(x)
        n.next = self.top
        self.top = n

    def pop(self):
        if not self.top:
            raise IndexError("empty")
        x = self.top.data
        self.top = self.top.next
        return x

    def peek(self):
        if not self.top:
            raise IndexError("empty")
        return self.top.data

    def is_empty(self):
        return self.top is None

۶ تمرین تمرین‌های کدنویسی — فصل ۲

  1. پشته را با لیست پیوندی یک‌طرفه پیاده کنید (همه عملیات O(1)).
  2. تابعی بنویسید که یک پشته را فقط با یک پشتهٔ کمکی معکوس کند.
  3. با دو پشته یک صف (FIFO) بسازید.
  4. تابع next_greater(arr): برای هر عنصر اولین عنصر بزرگ‌تر سمت راست را برگرداند (با پشته O(n)).
  5. عبارت postfix مثل 2 3 + 4 * را با پشته ارزیابی کنید.
  6. بررسی تعادل پرانتزها را برای چند نوع گسترش دهید و رشته‌های نامعتبر را تشخیص دهید.

راه‌حل و توضیح مفهومی — فصل ۲

۱) Stack با Linked List

مفهوم: TOP همیشه head است. push = insert_first، pop = delete_first. هر دو O(1) چون فقط اشاره‌گر head عوض می‌شود.

کد نمونه در بالا آمده است (StackLL).

۲) معکوس کردن پشته با یک پشتهٔ کمکی

مفهوم: همه عناصر را از s به aux منتقل کن (ترتیب برعکس می‌شود)، بعد دوباره به s برگردان. یا می‌توان با recursion هم معکوس کرد.
راه‌حل ۲
def reverse_stack(s: Stack):
    aux = Stack()
    while not s.is_empty():
        aux.push(s.pop())
    # حالا aux معکوس s است؛ برگردان
    while not aux.is_empty():
        s.push(aux.pop())
    # توجه: این دوباره ترتیب اولیه را برمی‌گرداند!
    # برای معکوس ماندن، فقط یک‌بار به aux منتقل کنید و از aux استفاده کنید
اگر می‌خواهید خود s معکوس بماند، بعد از انتقال به aux، عناصر aux را دوباره در s نریزید؛ یا از روش بازگشتی استفاده کنید.

۳) صف با دو پشته

مفهوم: یکی برای enqueue (ورودی)، یکی برای dequeue (خروجی). وقتی خروجی خالی شد، همه ورودی را به خروجی منتقل کن تا ترتیب FIFO شود.
راه‌حل ۳
class Queue2Stacks:
    def __init__(self):
        self.in_s = Stack()
        self.out_s = Stack()
    def enqueue(self, x):
        self.in_s.push(x)
    def dequeue(self):
        if self.out_s.is_empty():
            while not self.in_s.is_empty():
                self.out_s.push(self.in_s.pop())
        return self.out_s.pop()

۴) Next Greater Element

مفهوم: از راست به چپ (یا چپ به راست با پشته نزولی) حرکت کن. پشته اندیس‌هایی را نگه می‌دارد که هنوز «بزرگ‌تر بعدی» پیدا نکرده‌اند. وقتی عنصر بزرگ‌تری آمد، برای عناصر کوچک‌تر بالای پشته جواب ثبت می‌شود.
راه‌حل ۴
def next_greater(arr: list[int]) -> list[int]:
    n = len(arr)
    res = [-1] * n
    st = []  # اندیس‌ها
    for i in range(n):
        while st and arr[i] > arr[st[-1]]:
            res[st.pop()] = arr[i]
        st.append(i)
    return res
# مثال: [4,5,2,25] → [5,25,25,-1]

۵) ارزیابی postfix

مفهوم: عدد دیدید → push. عملگر دیدید → دو تا pop کنید، عمل را انجام دهید، نتیجه را push کنید. در پایان یک عنصر در پشته می‌ماند.
راه‌حل ۵
def eval_postfix(expr: str) -> int:
    s = Stack()
    for tok in expr.split():
        if tok in "+-*/":
            b, a = s.pop(), s.pop()
            if tok == '+': s.push(a + b)
            elif tok == '-': s.push(a - b)
            elif tok == '*': s.push(a * b)
            else: s.push(a // b)
        else:
            s.push(int(tok))
    return s.pop()
# "2 3 + 4 *" → 20

۶) تعادل پرانتزها

مفهوم: هر باز را push کن. هر بسته باید با آخرین باز جفت باشد. در پایان پشته باید خالی باشد. اگر بسته آمد و پشته خالی بود یا جفت نبود → نامعتبر.

کد balanced در متن فصل آمده است.

۳. صف و صف حلقوی — اولین ورودی، اولین خروجی

آنالوژی: صف نانوایی. کسی که اول آمده، اول نان می‌گیرد. کسی که آخر آمده، آخر می‌گیرد. این FIFO است: First In, First Out. درج از انتهای صف (rear)، حذف از ابتدای صف (front).

🎬 انیمیشن صف (FIFO) — خودت امتحان کن

صف خالی است
آبی = front (خروج)، نارنجی = rear (ورود). عناصر از راست وارد و از چپ خارج می‌شوند.

مشکل صف خطی: با هر حذف، خانه‌ی اول هدر می‌رود و دیگر استفاده نمی‌شود. وقتی rear به آخر آرایه برسد، حتی اگر اول صف خالی باشد، صف «پر» اعلام می‌شود.

Python — CQueue (صف حلقوی)
class CQueue:
    """صف حلقوی با ظرفیت ثابت."""

    def __init__(self, limit: int = 10) -> None:
        self.q = [None] * limit         # آرایه‌ی خالی با اندازه‌ی ثابت
        self.limit = limit
        self.front = self.rear = -1     # هر دو -1 یعنی صف خالی

    def is_empty(self) -> bool:
        return self.front == -1

    def is_full(self) -> bool:
        # یک خانه جلوتر از rear همان front باشد → پر
        return (self.rear + 1) % self.limit == self.front

    def insert(self, x) -> None:        # enqueue
        if self.is_full():
            raise OverflowError("queue is full")
        if self.is_empty():             # اولین عنصر
            self.front = self.rear = 0
        else:
            self.rear = (self.rear + 1) % self.limit  # حلقوی!
        self.q[self.rear] = x

    def delete(self):                   # dequeue
        if self.is_empty():
            raise IndexError("queue is empty")
        x = self.q[self.front]
        if self.front == self.rear:     # آخرین عنصر بود → خالی شود
            self.front = self.rear = -1
        else:
            self.front = (self.front + 1) % self.limit
        return x

    def display(self) -> None:
        if self.is_empty():
            print("empty"); return
        i = self.front
        while True:
            print(self.q[i], end=" ")
            if i == self.rear:
                break
            i = (i + 1) % self.limit
        print()


if __name__ == "__main__":
    q = CQueue(3)
    q.insert(1); q.insert(2); q.insert(3)
    q.delete()                          # 1 خارج شد
    q.insert(4)                         # حالا جا برای 4 هست
    q.display()                         # 2 3 4
توضیح خط‌به‌خط صف حلقوی:
  1. self.q = [None] * limit — آرایه‌ی ثابت‌اندازه؛ خانه‌های خالی None هستند.
  2. front = rear = -1 — نشانه‌ی «صف خالی». با اولین insert هر دو ۰ می‌شوند.
  3. is_full — اگر (rear+1) % limit == front باشد، یک خانه خالی هم نمانده (عمداً یک خانه را خالی نگه می‌داریم تا پر و خالی قاطی نشوند).
  4. insert — rear را با % جلو می‌برد (حلقوی) و مقدار را می‌نویسد.
  5. delete — مقدار front را برمی‌دارد، بعد front را با % جلو می‌برد. اگر front==rear بود، صف خالی می‌شود.
  6. display — از front شروع می‌کند و با % دور می‌زند تا به rear برسد.

def reverse_queue(q: CQueue) -> None:
    """صف را با کمک پشته معکوس می‌کند (درجا از نظر منطقی)"""
    s = Stack()
    while not q.is_empty():
        s.push(q.delete())
    while not s.is_empty():
        q.insert(s.pop())

  1. صف حلقوی را با شمارندهٔ size پیاده کنید تا نیازی به یک خانهٔ خالی عمدی نباشد.
  2. با یک صف، یک پشته بسازید (push و pop).
  3. تابع reverse_queue را بنویسید که صف را با پشته معکوس کند.
  4. صف اولویت ساده با لیست مرتب (insert O(n)، delete_min O(1)).
  5. شبیه‌سازی سادهٔ نوبت بانک: میانگین زمان انتظار را حساب کنید.
  6. با collections.deque مسئلهٔ sliding window maximum را در O(n) حل کنید.

راه‌حل و توضیح مفهومی — فصل ۳

۱) صف حلقوی با size

مفهوم: به‌جای یک خانه خالی عمدی، یک متغیر size نگه می‌داریم. پر وقتی size == limit، خالی وقتی size == 0. front و rear همیشه با % جلو می‌روند.
راه‌حل ۱
class CQueueSize:
    def __init__(self, limit=10):
        self.q = [None]*limit
        self.limit = limit
        self.front = 0
        self.rear = 0
        self.size = 0
    def is_full(self): return self.size == self.limit
    def is_empty(self): return self.size == 0
    def insert(self, x):
        if self.is_full(): raise OverflowError("full")
        self.q[self.rear] = x
        self.rear = (self.rear + 1) % self.limit
        self.size += 1
    def delete(self):
        if self.is_empty(): raise IndexError("empty")
        x = self.q[self.front]
        self.front = (self.front + 1) % self.limit
        self.size -= 1
        return x

۲) پشته با یک صف

مفهوم: برای push فقط enqueue کن. برای pop باید n-1 عنصر را dequeue و دوباره enqueue کنی تا عنصر آخر بیاید جلو — O(n).
راه‌حل ۲
from collections import deque
class StackFromQueue:
    def __init__(self):
        self.q = deque()
    def push(self, x):
        self.q.append(x)
    def pop(self):
        for _ in range(len(self.q)-1):
            self.q.append(self.q.popleft())
        return self.q.popleft()

۳) reverse_queue — کد نمونه در بالا.

مفهوم: صف FIFO است. اگر همه را در پشته بریزید (LIFO) و دوباره به صف برگردانید، ترتیب معکوس می‌شود.

۴) صف اولویت ساده

مفهوم: لیست را همیشه مرتب نگه می‌داریم (مثلاً صعودی). insert باید جای درست را پیدا کند O(n). delete_min = pop از ابتدا O(1).

۵ و ۶

نوبت بانک: برای هر مشتری زمان شروع سرویس = max(زمان رسیدن، زمان پایان نفر قبلی). انتظار = شروع − رسیدن.
Sliding window max: deque اندیس‌ها را به‌صورت نزولی از نظر مقدار نگه می‌دارد؛ از جلو عناصر خارج از پنجره و از عقب عناصر کوچک‌تر از عنصر جدید حذف می‌شوند.

۴. توابع بازگشتی — تابعی که خودش را صدا می‌زند

آنالوژی: تصور کنید می‌خواهید یک جعبه‌ی تو در تو را باز کنید. هر جعبه داخلش جعبه‌ی کوچک‌تری دارد. شما جعبه را باز می‌کنید، جعبه‌ی داخل را به دوستتان می‌دهید تا او باز کند، و همین‌طور ادامه می‌دهید تا به آخرین جعبه‌ی خالی برسید. بعد جواب‌ها یکی‌یکی برمی‌گردند. این همان بازگشت (Recursion) است.

هر تابع بازگشتی سه جزء دارد:

  1. شرط توقف (Base Case) — کی باید تمام شود؟ (وگرنه بی‌نهایت صدا می‌زند و برنامه می‌ترکد)
  2. مقدار بازگشت — وقتی شرط توقف برقرار شد، چه چیزی برگردانیم؟
  3. رابطه‌ی بازگشتی — مسئله را به مسئله‌ی کوچک‌تر تبدیل کن.

Python — توابع بازگشتی کلاسیک
def fact(n: int) -> int:
    """فاکتوریل: n! = n × (n-1)!"""
    if n <= 1:                  # شرط توقف
        return 1
    return n * fact(n - 1)      # رابطه‌ی بازگشتی


def fib(n: int) -> int:
    """فیبوناچی ساده — کند برای n بزرگ"""
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)


def fib_memo(n: int, memo: dict | None = None) -> int:
    """فیبوناچی با حافظه (Memoization) → O(n)"""
    if memo is None:
        memo = {}
    if n < 2:
        return n
    if n not in memo:                       # قبلاً حساب نشده؟
        memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo)
    return memo[n]


def is_palindrome(s: str) -> bool:
    """آیا رشته از دو طرف یکسان خوانده می‌شود؟"""
    if len(s) <= 1:                         # شرط توقف
        return True
    return s[0] == s[-1] and is_palindrome(s[1:-1])


def hanoi(n: int, src: str, aux: str, dst: str) -> None:
    """برج هانوی: n دیسک از src به dst با کمک aux"""
    if n == 1:
        print(src, "→", dst)
        return
    hanoi(n-1, src, dst, aux)               # n-1 تا را به کمکی ببر
    print(src, "→", dst)                    # بزرگ‌ترین را جابه‌جا کن
    hanoi(n-1, aux, src, dst)               # n-1 تا را روی مقصد بگذار

  1. if n <= 1: return 1 — شرط توقف حیاتی. بدون آن برنامه تا بی‌نهایت صدا می‌زند.
  2. return n * fact(n-1) — مسئله را به یک مسئله‌ی کوچک‌تر تبدیل می‌کند و منتظر جواب می‌ماند.
  3. در fib_memo: دیکشنری memo نتایج قبلی را نگه می‌دارد.
  4. if n not in memo — فقط اگر قبلاً حساب نشده، محاسبه کن و ذخیره کن.

def power(a, b):

    if b % 2 == 0:

    return a * power(a, b - 1)

def permutations(s):
    if len(s) <= 1: return [s]
    out = []
    for i, ch in enumerate(s):
        for p in permutations(s[:i] + s[i+1:]):
            out.append(ch + p)
    return out

۵. لیست پیوندی — زنجیره‌ای از نودها

from typing import Any, Optional

class Node:
    def __init__(self, data: Any) -> None:
        self.data = data        # محتوای نود
        self.next = None        # اشاره‌گر به نود بعدی


class LinkedList:
    def __init__(self) -> None:
        self.head: Optional[Node] = None   # شروع زنجیره

    def insert_first(self, x) -> None:
        """درج در ابتدا — O(1)"""
        n = Node(x)
        n.next = self.head      # نود جدید به سر قبلی اشاره کند
        self.head = n           # سر جدید شود

    def insert_last(self, x) -> None:
        """درج در انتها — O(n)"""
        n = Node(x)
        if not self.head:       # لیست خالی بود
            self.head = n
            return
        t = self.head
        while t.next:           # تا آخر برو
            t = t.next
        t.next = n              # آخری به نود جدید اشاره کند

    def delete_first(self) -> None:
        if self.head:
            self.head = self.head.next   # سر را یکی جلو ببر

    def show(self) -> None:
        t, out = self.head, []
        while t:
            out.append(str(t.data))
            t = t.next
        print(" → ".join(out) + " → None")


if __name__ == "__main__":
    L = LinkedList()
    L.insert_last(20)
    L.insert_last(30)
    L.insert_first(10)
    L.show()    # 10 → 20 → 30 → None
    L.delete_first()
    L.show()    # 20 → 30 → None
توضیح خط‌به‌خط LinkedList:
  1. Node — هر نود دو فیلد دارد: data (محتوا) و next (آدرس نود بعدی).
  2. self.head — فقط آدرس اولین نود را نگه می‌داریم. بقیه از طریق زنجیره‌ی next پیدا می‌شوند.
  3. insert_first — نود جدید می‌سازد، n.next را به head فعلی وصل می‌کند، بعد head را عوض می‌کند. دو خط → O(1).
  4. insert_last — باید تا آخر لیست برود (while t.next)، بعد وصل کند → O(n).
  5. delete_first — فقط head را یکی جلو می‌برد. نود قبلی دیگر قابل دسترس نیست و زباله‌روب آزادش می‌کند.
  6. show — از head شروع می‌کند و تا رسیدن به None پیمایش می‌کند.
ترتیب طلایی اشاره‌گرها: همیشه اول new.next = t.next را تنظیم کنید، بعد t.next = new. اگر برعکس کنید، بقیه‌ی لیست گم می‌شود!

class DNode:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None

    def insert_first(self, x):
        n = DNode(x)
        if not self.head:
            self.head = self.tail = n
            return
        n.next = self.head
        self.head.prev = n
        self.head = n

    def insert_last(self, x):
        n = DNode(x)
        if not self.tail:
            self.head = self.tail = n
            return
        n.prev = self.tail
        self.tail.next = n
        self.tail = n

    def delete_first(self):
        if not self.head: return
        if self.head is self.tail:
            self.head = self.tail = None
            return
        self.head = self.head.next
        self.head.prev = None

    def delete_last(self):
        if not self.tail: return
        if self.head is self.tail:
            self.head = self.tail = None
            return
        self.tail = self.tail.prev
        self.tail.next = None

    def show(self):
        t, out = self.head, []
        while t:
            out.append(str(t.data))
            t = t.next
        print(" ⇄ ".join(out) if out else "empty")

def reverse_list(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev  # head جدید

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

۶. درخت — ساختار سلسله‌مراتبی

آنالوژی: شجره‌نامه‌ی خانوادگی. یک نفر در رأس (ریشه / Root)، فرزندان، نوه‌ها و ... . هر کس فقط یک پدر دارد (به‌جز ریشه). برگ‌ها کسانی هستند که فرزندی ندارند.

مفاهیم کلیدی:

  • ریشه (Root) — بالای درخت
  • برگ (Leaf) — نود بدون فرزند
  • درجه‌ی نود — تعداد فرزندان
  • ارتفاع — طولانی‌ترین مسیر از ریشه تا یک برگ
  • درخت دودویی — هر نود حداکثر ۲ فرزند دارد

درخت جست‌وجوی دودویی (BST)

قانون طلایی: چپ < پدر < راست. این قانون باعث می‌شود جست‌وجو، درج و حذف در حالت متوسط O(log n) باشد.

🎬 انیمیشن درخت جست‌وجوی دودویی (BST)

درخت خالی — عددی وارد کن و درج بزن (قانون: چپ < پدر < راست)
هر عدد از ریشه شروع می‌کند و با مقایسه چپ/راست جای خالی پیدا می‌کند. نود نارنجی = آخرین درج.
Python — BST ساده
class BNode:
    def __init__(self, d) -> None:
        self.data = d
        self.left = None
        self.right = None


class BST:
    def __init__(self) -> None:
        self.root = None

    def add(self, x) -> None:
        if not self.root:
            self.root = BNode(x)
            return
        t = self.root
        while True:
            if x == t.data:
                return              # تکراری قبول نمی‌کنیم
            if x < t.data:
                if t.left is None:
                    t.left = BNode(x)
                    return
                t = t.left
            else:
                if t.right is None:
                    t.right = BNode(x)
                    return
                t = t.right

    def search(self, x) -> bool:
        t = self.root
        while t and t.data != x:
            t = t.left if x < t.data else t.right
        return t is not None

    def inorder(self) -> list:
        """میان‌ترتیب همیشه لیست مرتب می‌دهد"""
        result = []
        def walk(n):
            if n:
                walk(n.left)
                result.append(n.data)
                walk(n.right)
        walk(self.root)
        return result


if __name__ == "__main__":
    b = BST()
    for v in (13, 11, 15, 9, 12, 14, 17):
        b.add(v)
    print(b.inorder())      # [9, 11, 12, 13, 14, 15, 17]
    print(b.search(14))     # True
    print(b.search(99))     # False
توضیح خط‌به‌خط BST.add:
  1. اگر ریشه None باشد، نود جدید ریشه می‌شود.
  2. از ریشه شروع می‌کنیم و در یک حلقه بی‌نهایت (while True) حرکت می‌کنیم.
  3. اگر x == t.data — تکراری است، کاری نمی‌کنیم.
  4. اگر x < t.data — باید به چپ برویم. اگر چپ خالی بود، همان‌جا درج کن؛ وگرنه t = t.left.
  5. اگر x > t.data — همین منطق برای راست.
  6. جست‌وجو دقیقاً همین مسیر را می‌رود؛ اگر به None رسید یعنی نبود.

هیپ (Heap) — درخت کامل با اولویت

در Max-Heap هر پدر از فرزندانش بزرگ‌تر است. ریشه همیشه بزرگ‌ترین عنصر است. در لیست ذخیره می‌شود: فرزندان نود i در خانه‌های 2i+1 و 2i+2.

Python — MaxHeap
class MaxHeap:
    def __init__(self) -> None:
        self.a: list = []

    def insert(self, x) -> None:
        self.a.append(x)                # به انتها اضافه کن
        self._up(len(self.a) - 1)       # به بالا حباب بزن

    def _up(self, n: int) -> None:
        while n > 0:
            p = (n - 1) // 2            # پدر
            if self.a[n] <= self.a[p]:
                break
            self.a[n], self.a[p] = self.a[p], self.a[n]
            n = p

    def del_root(self):
        if not self.a:
            raise IndexError("heap is empty")
        top = self.a[0]
        last = self.a.pop()
        if self.a:
            self.a[0] = last
            self._down(0)               # به پایین حباب بزن
        return top

    def _down(self, n: int) -> None:
        while True:
            big = n
            l, r = 2*n+1, 2*n+2
            if l < len(self.a) and self.a[l] > self.a[big]:
                big = l
            if r < len(self.a) and self.a[r] > self.a[big]:
                big = r
            if big == n:
                return
            self.a[n], self.a[big] = self.a[big], self.a[n]
            n = big

    for v in (10, 40, 15, 50, 100):
        h.insert(v)
    print([h.del_root() for _ in range(5)])

  1. insert — عنصر را به انتهای لیست اضافه می‌کند، بعد _up را صدا می‌زند.
  2. _up (bubble up) — تا وقتی پدر کوچک‌تر باشد، با پدر جابه‌جا می‌شود. اندیس پدر: (i-1)//2.
  3. del_root — ریشه (بزرگ‌ترین) را برمی‌دارد، آخرین عنصر را جای ریشه می‌گذارد، بعد _down.
  4. _down (bubble down) — با بزرگ‌ترین فرزند جابه‌جا می‌شود تا ترتیب هیپ درست شود. فرزندان: 2i+1 و 2i+2.
  5. هر دو عملیات O(log n) هستند چون ارتفاع درخت کامل حدود log n است.

class BST:
    # ... add و search مثل متن اصلی ...
    def _min_node(self, n):
        while n.left:
            n = n.left
        return n

    def delete(self, x):
        self.root = self._delete(self.root, x)

    def _delete(self, n, x):
        if n is None:
            return None
        if x < n.data:
            n.left = self._delete(n.left, x)
        elif x > n.data:
            n.right = self._delete(n.right, x)
        else:
            if n.left is None:
                return n.right
            if n.right is None:
                return n.left
            succ = self._min_node(n.right)
            n.data = succ.data
            n.right = self._delete(n.right, succ.data)
        return n

۶ تمرین تمرین‌های کدنویسی — فصل ۶

  1. تابع is_bst(root) بنویسید که اعتبار BST را چک کند.

  3. پیمایش سطح‌به‌سطح (BFS) درخت با صف.

  5. Min-Heap کامل و Heap Sort پیاده کنید.
  6. با del_root متوالی از MaxHeap آرایه را نزولی مرتب کنید و پیچیدگی را بنویسید.

۱) is_bst

مفهوم: هر نود باید در بازه (min, max) مجاز باشد. برای چپ max=data نود، برای راست min=data نود. از -∞ و +∞ شروع کنید.
راه‌حل ۱
def is_bst(n, lo=float('-inf'), hi=float('inf')):
    if n is None: return True
    if not (lo < n.data < hi): return False
    return is_bst(n.left, lo, n.data) and is_bst(n.right, n.data, hi)

۲) min / max بدون بازگشت

مفهوم: در BST همیشه چپ‌ترین = کمینه، راست‌ترین = بیشینه. فقط یک حلقه while.

۳) BFS درخت

مفهوم: صف. ریشه را بگذار، هر بار یکی بردار و فرزندانش را به صف اضافه کن — همان سطح‌به‌سطح.

۴) شمارش برگ

مفهوم: اگر نود left و right نداشته باشد برگ است. در غیر این صورت مجموع برگ‌های زیردرخت چپ و راست.

۵ و ۶) Heap Sort

مفهوم: n بار insert → O(n log n)، بعد n بار del_root → O(n log n). خروجی MaxHeap نزولی است؛ MinHeap صعودی.

۷. گراف — شبکه‌ی رئوس و یال‌ها

آنالوژی: نقشه‌ی شهرها و جاده‌ها. هر شهر یک رأس (Vertex)، هر جاده یک یال (Edge). اگر جاده یک‌طرفه باشد، گراف جهت‌دار است. اگر وزن (فاصله) داشته باشد، وزن‌دار است. 
BFS (صف) — سطح‌به‌سطح          DFS (پشته/بازگشت) — تا عمق

Python — Graph با ماتریس مجاورت
from collections import deque

class Graph:
    def __init__(self, n: int, directed: bool = False) -> None:
        self.n = n
        self.directed = directed
        self.m = [[0]*n for _ in range(n)]   # ماتریس n×n

    def insert_edge(self, s: int, t: int, w: int = 1) -> None:
        self.m[s][t] = w
        if not self.directed:
            self.m[t][s] = w                 # دوطرفه

    def bfs(self, start: int) -> list[int]:
        """پیمایش سطح‌به‌سطح با صف"""
        seen, q, order = {start}, deque([start]), []
        while q:
            u = q.popleft()
            order.append(u)
            for v in range(self.n):
                if self.m[u][v] and v not in seen:
                    seen.add(v)
                    q.append(v)
        return order

    def dfs(self, start: int, seen: set | None = None) -> list[int]:
        """پیمایش عمقی با بازگشت"""
        if seen is None:
            seen = set()
        seen.add(start)
        order = [start]
        for v in range(self.n):
            if self.m[start][v] and v not in seen:
                order += self.dfs(v, seen)
        return order

توضیح خط‌به‌خط BFS و DFS:
  1. seen — مجموعه‌ی رأس‌های دیده‌شده تا دوباره نرویم (جلوگیری از حلقه).
  2. BFS: صف (deque). اول رأس را از صف برمی‌داریم، بعد همه‌ی همسایه‌های ندیده را به صف اضافه می‌کنیم → سطح‌به‌سطح.
  3. DFS: بازگشت (یا پشته). رأس فعلی را علامت می‌زنیم، بعد اولین همسایه‌ی ندیده را صدا می‌زنیم و تا عمق می‌رویم.
  4. ماتریس مجاورت: m[u][v] != 0 یعنی یال وجود دارد.
  5. زمان با ماتریس: O(V²) چون برای هر رأس همه‌ی ستون‌ها را چک می‌کنیم.

class WeightedDiGraph:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]  # list of (v, w)

    def add_edge(self, u, v, w):
        self.adj[u].append((v, w))

    def bfs_order(self, start):
        from collections import deque
        seen, q, order = {start}, deque([start]), []
        while q:
            u = q.popleft()
            order.append(u)
            for v, _ in self.adj[u]:
                if v not in seen:
                    seen.add(v)
                    q.append(v)
        return order

۱) DFS با پشته

مفهوم: به‌جای call stack سیستم، خودتان پشته بسازید. رأس را push کنید، وقتی pop شد همسایه‌های ندیده را push کنید.
راه‌حل ۱
def dfs_iter(g, start):
    seen, st, order = set(), [start], []
    while st:
        u = st.pop()
        if u in seen: continue
        seen.add(u)
        order.append(u)
        for v in range(g.n):
            if g.m[u][v] and v not in seen:
                st.append(v)
    return order

۶) Dijkstra ساده

مفهوم: همیشه رأسی را که فاصلهٔ قطعی کمتری دارد انتخاب کنید، فاصله همسایه‌ها را در صورت بهتر شدن به‌روز کنید. با آرایه O(V²) می‌شود؛ برای گراف خلوت بهتر است از heap استفاده شود.
راه‌حل ۶ (ساده)
def dijkstra(g, src):
    INF = 10**9
    dist = [INF]*g.n
    dist[src] = 0
    used = [False]*g.n
    for _ in range(g.n):
        u = -1
        for i in range(g.n):
            if not used[i] and (u == -1 or dist[i] < dist[u]):
                u = i
        if dist[u] == INF: break
        used[u] = True
        for v, w in g.adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    return dist
